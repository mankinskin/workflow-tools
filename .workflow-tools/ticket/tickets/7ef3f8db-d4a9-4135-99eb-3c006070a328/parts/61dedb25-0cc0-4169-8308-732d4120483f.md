- Resolver tests cover strict single-parent inheritance, missing parents, cycles, and deterministic resolved output.
- Lifecycle validation accepts only directed transitions that preserve a valid plan/act/verify path and keeps relation edges outside lifecycle validation.
- Registry reload rejects invalid or colliding generations atomically and retains the prior valid generation.
