## Required documentation examples

- Minimal direct-corpus plan/install flow with a prompt file and one dependency.
- Source-published recipe flow showing declared download/generation/compile staging and permissions.
- Local project/user profile flow without a global registry.
- Repository, user, system, and explicit destination examples with safe and rejected paths.
- Existing-submodule placement and absent-submodule canonical fallback with rewritten link examples.
- Clean audit, blocked non-guidance reference, unsupported dependency, unsafe path, and missing target output examples.
- Autofix plan versus explicit apply, stale-report refusal, and post-audit rollback examples.
- Deterministic fixture command, Docker command, and network smoke command with separate evidence labels.
