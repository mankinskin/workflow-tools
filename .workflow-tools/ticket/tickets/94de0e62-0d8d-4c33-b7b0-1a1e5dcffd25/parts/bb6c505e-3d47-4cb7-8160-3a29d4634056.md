## Follow-up: relocate mcp-toolmon, toolmon-costgate/policy-api, worktree-ctl, model-prices

Completed the second follow-up: moved the mcp-toolmon MCP middleware stack, worktree-ctl, and the
model-prices data table into `workflow-tools/session/crates/` since they are tightly coupled to
the session harness (mcp-toolmon depends on session-api/session-workspace-resolver;
worktree-ctl depends on session-worktree-provision; model-prices feeds session-api's
price_loader).

New layout under `workflow-tools/session/crates/`:
- `mcp-toolmon/` (moved from `memory-api/tools/mcp/mcp-toolmon`)
- `toolmon-costgate/` (moved from `memory-api/tools/mcp/toolmon-costgate`)
- `toolmon-policy-api/` (moved from `memory-api/tools/mcp/toolmon-policy-api`)
- `worktree-ctl/` (moved from `tools/worktree/worktree-ctl`)
- `model-prices/` (moved from `tools/model-prices`, now a sibling of `toolmon-costgate` as requested)

Dependency fixes: mcp-toolmon's `session-api`/`session-workspace-resolver` and worktree-ctl's
`session-worktree-provision` switched from git deps to local sibling `path = "../..."`;
toolmon-costgate/toolmon-policy-api needed no dep changes (relative sibling path preserved).
`session-api::price_loader` now resolves `workflow-tools/session/crates/model-prices/model_prices.json`
relative to repo root instead of the old `tools/model-prices/...`. worktree-ctl's
`worktree_contracts.rs` `workspace_root()` test helper ancestor depth adjusted (3→4) for the
crate's new nesting depth.

Wiring updated: root `Cargo.toml` members; `tools/install/artifacts.toml` and `COMMANDS.md`
source_path for `mcp-toolmon`/`worktree-ctl`; `.vscode/mcp.json` and `.github/mcp.json`
`COST_GATE_TABLE` (22 occurrences) repointed to the new model-prices path; living orchestration
docs (`model-prices.instructions.md`, `model-routing.instructions.md`,
`orchestrator-delegation.instructions.md`, `orchestrator.agent.md`, `sync-model-prices.prompt.md`)
path references updated. The large body of historical ticket/spec prose referencing the old
`tools/model-prices/...` path was intentionally left untouched (archival record, out of scope
for a mechanical relocation).

**Known limitation (flagged, not fixed)**: `model-prices` and `mcp-toolmon`/`worktree-ctl` now
live inside a nested submodule-of-submodule (`workflow-tools/session`). `worktree-ctl bootstrap`
only populates direct submodules of context-engine one level deep; a freshly bootstrapped
worktree needs a manual `git submodule update --init` inside `workflow-tools` for
`workflow-tools/session` (and any other nested domain repo) to be populated — hit and worked
around twice this session. Fixing `worktree-ctl`'s bootstrap to recurse into submodules-of-
submodules is a separate, non-trivial follow-up ticket, not undertaken here to keep scope tight.
