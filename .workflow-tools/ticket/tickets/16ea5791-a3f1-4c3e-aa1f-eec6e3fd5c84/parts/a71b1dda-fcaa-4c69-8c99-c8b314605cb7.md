Requirements:
- Scope only configured VS Code/Copilot lifecycle hooks; exclude Cline, other hook systems, hook installation/relocation, command execution changes, unrelated MCP semantics, and broad event-schema redesign.
- Persist exactly one event per invocation with stable `invocation_id`, `lifecycle_trigger`, configured command/path, and available completion/exit outcome.
- Preserve all available Session API session/turn/tool-call correlation without synthesizing absent values.
- A failure/nonzero exit remains an event; each retry is a distinct invocation with a distinct identity.
- Do not accept or persist raw hook-log text.
- External-dependency policy: no new external dependency; extend existing Session API/event and configured-hook adapter boundaries only.
- Ownership: Session API owns the canonical event type, persistence/query semantics, and correlation vocabulary; the configured-hook adapter owns mapping observed execution into that type. log-api is only a downstream consumer of supplied identities.
