## Validation contract

### Commands

1. `cargo test -p install-ctl guidance` must pass all existing tests unmodified plus the new `get`-focused tests.
2. `cargo run -p install-ctl -- guidance get --help` must exit 0 and document every flag from AC1.
3. `cargo run -p install-ctl -- guidance plan --help` / `install --help` / `autofix --help` must be byte-identical to their pre-change output (AC2 regression guard).

### Required evidence

- A profile-less fixture asserting the synthesized implicit profile installs exactly the selected path plus its Markdown closure.
- An explicit-profile fixture asserting `--profile` resolves against the cloned checkout, not the caller's working directory.
- A `--keep-checkout` fixture asserting the directory survives and its path is printed.
- A blocking-plan fixture asserting zero writes to `--target` and cleanup still occurs without `--keep-checkout`.
- A clone-failure fixture (invalid path/URL through the injectable clone seam) asserting no plan/install attempt and no leftover managed directory.
- An idempotence fixture asserting a second `get` run reports no uncontrolled changes.
- A rejection fixture asserting an absolute or traversal `--select` path is rejected before any clone/plan/install side effect beyond the (test-injected) clone step.

### Exit criteria

All AC1-AC10 have command-backed evidence; no existing `plan`/`install`/`autofix` test result changes; `git diff --check` is clean for touched files; `install/README.md` documents `get` accurately against its actual `--help` output.
