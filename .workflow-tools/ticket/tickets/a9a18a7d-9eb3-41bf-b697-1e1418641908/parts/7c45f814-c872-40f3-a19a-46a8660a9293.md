## Acceptance Criteria

1. Focused memory-kernel tests cover canonical-only, legacy-only, both-present, and neither-present cases for ticket, spec, test, session, feedback, log, doc, rule, and audit domains.
2. Legacy-only read resolution returns the original store root plus a deprecation diagnostic naming the canonical destination.
3. Write/initialization resolution never returns a legacy path.
4. Recursive discovery reports canonical nested stores exactly once and still prunes store internals, `.git`, `target`, and `node_modules`.
5. Existing flat-layout tests remain covered by the compatibility read path.
