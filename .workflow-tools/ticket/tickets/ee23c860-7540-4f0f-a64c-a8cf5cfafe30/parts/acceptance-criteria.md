- **MN-W1-01**: Expose the six shared states while retaining native state and revision; Ticket planning/ready -> planned, in-implementation/in-review -> active, on-hold -> paused, done -> completed and cancelled -> cancelled. A schema-provided blocked state maps to blocked; an unknown native state returns ticket_state_unmapped, never a fallback.
- **MN-W1-02**: Ticket-backed waypoints read current state from the explicit owning Ticket store. A Mission cannot overwrite that state; transition adapters invoke the Ticket domain and preserve its history and legal-state checks.
- **MN-W1-03**: Separate planning, approval, pause/resume, cancellation, completion/result review, handoff and reopen capabilities. Unsupported capabilities return an explicit diagnostic and do not pretend to succeed.
- **MN-W1-04**: Preserve stable waypoint identity and existing native/typed read compatibility. The shared abstraction owns types and capability contracts only; domain persistence and revisions remain in their current stores.
