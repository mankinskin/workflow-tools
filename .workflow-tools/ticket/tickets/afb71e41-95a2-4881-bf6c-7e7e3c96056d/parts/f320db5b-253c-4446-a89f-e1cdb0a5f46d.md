## Implementation plan: audit extraction

### Established baseline
`memory-api/crates/memory-api` is deleted. Commit `memory-kernel` as `memory_kernel = { git = "https://github.com/mankinskin/memory-kernel", branch = "main" }`; use relative paths only in a root `[patch]` development override (ticket `1b7e0c3d` proved patch-free remote resolution).

Create public crate `audit` re-exporting internal `audit-api`, with no default features and feature-gated bare `audit` and `audit-mcp` bins on `transport-harness` from `memory-kernel`, following the ticket-pilot consolidation shape (`26da8f59`). Keep audit-specific typed `EntityManifest` accessors, if present, as `audit-api` extension traits with unchanged `extra` keys; never in the neutral kernel.

### Verified source surface
- API: `memory-api/crates/audit-api` (consumes `rule-api`).
- Legacy transports to consolidate first: `memory-api/tools/cli/audit-cli`, `memory-api/tools/mcp/audit-mcp`.
- No `audit-http` or viewer exists.

### Consumers to repoint
`memory-api/crates/memory-matrix` consumes `audit-api` outside audit's own transports.

### Execution
1. Consolidate `audit-cli` and `audit-mcp` into feature-gated `audit` and `audit-mcp` bins in the public `audit` crate, retaining their tests and command behavior.
2. Move `audit-api` and the consolidated `audit` crate into the standalone audit repository.
3. Repoint `memory-matrix` and any other identified consumer to the published git dependency before deleting old workspace paths.
4. Sequence audit extraction strictly after `rule` (`21893f5f`) — `audit-api`'s only confirmed sibling-tool dependency is `rule-api`, not the broader spec/session/rule set assumed in an earlier draft of this plan.

### Acceptance criteria
```bash
cargo test -p audit-api -p audit-cli -p audit-mcp
cargo build --manifest-path "$TOOL_REPO/Cargo.toml" --no-default-features
cargo test --manifest-path "$TOOL_REPO/Cargo.toml" --all-features
cargo test --workspace
```

### Risk
Standalone validation requires a published `memory-kernel` and a published `rule` (since `audit-api` depends on `rule-api`). Do not mask a missing publication with a committed local path.
