## Repo map

repo_map.toon is produced by the peek CLI. Refresh when workspace layout or agent files change:

cargo run -p peek-cli -- . --repo-map --output repo_map.toon
git add repo_map.toon

Agent customization files and global policy live in AGENTS.md. See [AGENTS.md](../../../AGENTS.md) for repository-wide principles and ownership rules.
